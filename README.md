# 📅 Monthly Habit Tracker

A clean and responsive **Monthly Habit Tracker Web App** that helps users build consistency by tracking daily habits, maintaining streaks, and visualizing progress through analytics and charts.

This project is fully frontend-based and works completely offline using browser **localStorage**.

---

## ✨ Features

### 📝 Habit Tracking
- Add, edit, and delete habits
- Track habits daily using ✔ (completed) and ✖ (missed)
- Supports up to 25 habits per month
- Month and year selection

### 🔥 Streak System
- Current streak per habit
- Longest streak tracking
- Visual streak badges
- Streak resets automatically when a habit is missed

### 📊 Analytics Dashboard
- Total habits count
- Total checkmarks completed
- Monthly completion rate
- Most completed habit
- Least completed habit

### 📋 Habit-wise Analytics
For each habit:
- Completion percentage
- Days completed
- Days missed
- Current streak
- Longest streak

### 📈 Visual Charts
- Daily progress line chart
- Auto-updating graphs based on user input

### 💾 Data Persistence
- All data stored using **localStorage**
- Progress remains saved after page reload or browser restart

### 🖨 PDF Export
- Export habit tracker and analytics as a printable PDF report

### 🎨 UI/UX
- Clean grid-based layout (inspired by paper habit trackers)
- Light / Dark mode toggle
- Fully responsive design

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- localStorage
- Chart Library (for graphs)
